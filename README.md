# Abol Store

فروشگاه محصولات دیجیتال کالاف دیوتی موبایل (CP، اکانت، کمبو) — ساخته‌شده با Next.js 16 + Prisma 7 + SQLite. رابط کاملاً فارسی و RTL.

## امکانات

- **فروشگاه عمومی:** صفحه اصلی دیتابیس‌محور، لیست محصولات با فیلتر دسته/جستجو، صفحه محصول، سبد خرید، چک‌اوت مهمان، کد تخفیف، پیگیری سفارش، وبلاگ، فرم پشتیبانی.
- **چک‌اوت کارت‌به‌کارت:** آپلود رسید، بررسی ادمین (تأیید/رد با دلیل)، تاریخچه وضعیت.
- **حساب مشتری:** ثبت‌نام با موبایل، داشبورد سفارش‌ها، پروفایل، ثبت نظر برای سفارش‌های تکمیل‌شده.
- **پنل ادمین:** داشبورد آماری، مدیریت سفارش‌ها (رسید، یادداشت، لغو، تأیید موبایل)، محصولات و دسته‌بندی‌ها (ویژگی‌ها، فیلدهای چک‌اوت)، کدهای تخفیف، انتشار نظرات، وبلاگ، صندوق پشتیبانی، تنظیمات فروشگاه.

## راه‌اندازی (توسعه)

```bash
npm install
cp .env.example .env   # سپس مقادیر را تنظیم کنید
npm run db:migrate     # اجرای مهاجرت اولیه
npm run db:seed        # ساخت ادمین + دیتای نمونه (idempotent)
npm run dev            # http://localhost:3000
```

مدیر (seed): شماره و رمز از `ADMIN_PHONE` / `ADMIN_PASSWORD` در `.env`.

## دستورات

| فرمان | توضیح |
| --- | --- |
| `npm run dev` | سرور توسعه |
| `npm run build` / `npm run start` | بیلد و اجرای تولید |
| `npm run typecheck` / `npm run lint` | بررسی نوع و لینت |
| `npm test` | تست‌های واحد + یکپارچه‌سازی (Vitest) |
| `npm run test:e2e` | تست‌های مرورگر (Playwright — از Edge/Chrome نصب‌شده استفاده می‌کند) |
| `npm run check` | اجرای کامل typecheck + lint + test + build |
| `npm run db:migrate` | اعمال مهاجرت‌ها |
| `npm run db:seed` | دیتای نمونه |
| `npm run db:studio` | Prisma Studio |

## امنیت

- پسوردها bcrypt؛ سشن‌های HTTP-only با هش توکن.
- قیمت‌ها همیشه سمت سرور محاسبه می‌شوند (اعتماد صفر به کلاینت).
- محدودیت تلاش ورود ادمین و فرم پشتیبانی (in-memory — برای چند-نمونه از Redis استفاده کنید).
- SQLite فقط برای توسعه؛ برای تولید به PostgreSQL مهاجرت کنید (راهنما در docs).
